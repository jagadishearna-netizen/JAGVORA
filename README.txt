JAGVORA WEBSITE MVP
===================

Files
- index.html      Main webpage
- styles.css      Responsive corporate styling
- script.js       Mobile menu + mini health-check scoring
- assets/         JAGVORA logo and website visuals

Open locally
1. Extract the ZIP.
2. Double-click index.html.

Publish free with GitHub Pages
1. Create a free GitHub account/repository (for example: jagvora-site).
2. Upload all files from the jagvora_website folder to the repository root.
3. In GitHub: Settings > Pages > Deploy from branch > main / root.
4. GitHub will provide a free github.io address.

Before public launch
- Replace hello@jagvora.example in index.html with the official JAGVORA email.
- Complete formal company-name/trademark/domain clearance.
- Review Privacy Policy, Terms, cookie/analytics requirements for target markets.
- Add real customer results/testimonials only when documented and authorized.
- Do not claim ISO certification unless formally certified.
